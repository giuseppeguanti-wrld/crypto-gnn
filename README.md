# crypto-gnn-forecasting

Graph Neural Network framework for multi-asset cryptocurrency forecasting using dynamic correlation graphs.

Bachelor's thesis project (*Graph Neural Network per la previsione multi-asset di criptovalute*, written in Italian). A rolling-window correlation graph over 15 cryptocurrencies feeds a two-layer GCN (Kipf & Welling), which is compared against VAR, per-asset AR and naive forecasts under a walk-forward protocol with no-look-ahead tests. The same graphs are used to study how market topology changes between calm regimes and crises (China mining crackdown 2021, Terra/Luna, FTX).

The outcome is reported as measured: no model beats the zero forecast, and the GCN is indistinguishable from its graph-free ablation. See `project-thesis/results/summary.md` for all the numbers.

## Repository layout

| Folder | Contents |

The two folders are independent. Each has its own README with full instructions.

## Quick start

**Experiments** (Python 3.13+, [uv](https://docs.astral.sh/uv/), CPU only):

```powershell
cd project-thesis
uv venv; .venv\Scripts\Activate.ps1
uv pip install torch --index-url https://download.pytorch.org/whl/cpu
uv pip install -r requirements.txt
uv pip install -e . --no-deps

pytest tests/ -q
python scripts/01_download_data.py   # then 02 … 08, in order
streamlit run app/streamlit_app.py
```

**Thesis** (TeX distribution with `biber`; Pygments on `PATH` for `minted`):

```powershell
cd latex-thesis
latexmk -pdf -bibtex -shell-escape main.tex
```
