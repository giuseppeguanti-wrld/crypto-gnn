# Thesis — LaTeX sources

Sources of the thesis *Graph Neural Network per la previsione multi-asset di criptovalute* (written in Italian).

## Structure

```
latex-thesis/
├── main.tex            # main document, \input of every part
├── preamble.tex        # packages and configuration
├── frontmatter/        # titlepage, dedication, disclaimer, abstract, acronyms, acknowledgements
├── chapters/
│   ├── 01-introduction.tex                  # Introduzione (unnumbered)
│   ├── 01-project-overview.tex              # Panoramica del progetto (unnumbered)
│   ├── 02-graph-laplacian-theory.tex        # Chapter 1
│   ├── 03-forecasting-models.tex            # Chapter 2
│   ├── 04-returns-correlation-and-graphs.tex  # Chapter 3
│   ├── 05-topological-evolution.tex         # Chapter 4
│   ├── 06-training-and-comparison.tex       # Chapter 5
│   ├── 07-backtest.tex                      # Chapter 6
│   └── 08-conclusions.tex                   # Chapter 7
├── bibliography/
│   └── references.bib
├── figures/            # PDFs generated by ../project-thesis/scripts/07_make_figures.py
└── tables/             # tables generated by ../project-thesis/
```

File numbers do not match chapter numbers, because the first two files are unnumbered chapters.

## Build

Requires a TeX distribution with `biber` (TeX Live or MiKTeX) and [Pygments](https://pygments.org/) on `PATH`: the code snippets use `minted`, which needs `-shell-escape`.

```bash
cd latex-thesis
latexmk -pdf -bibtex -shell-escape main.tex
```

Or by hand:

```bash
pdflatex -shell-escape main.tex
biber main
pdflatex -shell-escape main.tex
pdflatex -shell-escape main.tex
```
